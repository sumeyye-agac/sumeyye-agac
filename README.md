# Hi, I'm Sumeyye 👋

Machine learning scientist with a PhD in Computer Engineering (Bogazici University). I specialize in compressing deep learning models for devices with limited memory and compute. My repos cover the full path: collecting sensor data, training models, compressing them, and testing them for on-device use.

### Data I've worked with

- IMU motion signals (accelerometer, gyroscope), the core of my PhD
- Physiological signals: ECG, heart rate, HRV, body temperature (Movesense)
- Earable sensor data (DreamCatcher benchmark)
- Consumer wearable data: sleep, steps, activity (Fitbit)
- Also some computer vision (pose estimation, image classification) and text

### What you'll find here

- Sensor-based human activity recognition and event detection
- Model efficiency: pruning, knowledge distillation, TF Lite conversion, edge benchmarks
- Real-time sensor streaming and data collection (BLE to browser dashboards)
- LLM agents and MCP servers over sensor data
- From-scratch implementations and older course projects

### Stack

Python · PyTorch · TensorFlow / TF Lite · Streamlit · FastAPI · WebSocket / BLE · Claude API · MCP

*Currently exploring what LLM agents can do with wearable data.*
